TuneScript AI V0.4 — 音乐转谱器
================================

把音频识别为钢琴 MIDI + 五线谱 PDF + 钢琴演奏 WAV。

V0.4 更新
---------
- 分轨升级为 6 轨(htdemucs_6s)：人声/鼓/贝斯/吉他/钢琴/其他
- 伴奏细分：吉他与钢琴单独分出，和弦识别更贴近原曲
- 分离更快（6 轨模型反而比 4 轨更快约 42%）
- 分离出的 6 轨 wav 会一并保存

运行要求
--------
- Windows 10 / 11
- 已安装 MuseScore Studio 4（渲染五线谱 PDF 与钢琴音色 WAV 需要）
- 首次运行需联网：下载分离模型约 100MB，缓存后离线可用

使用
----
1. 双击 TuneScript AI V0.4.exe 启动
2. 选择音频文件
   - WAV / FLAC / OGG 直接识别
   - MP3 / M4A 等需同目录的 ffmpeg.exe（本包已附带）
   - NCM（网易云音乐加密文件）会自动解密后识别
3. 选择输出目录，点「开始转谱」

模式
----
- 默认：6 轨分离（人声+吉他/钢琴和弦识别，更准更干净）
- 简洁模式（勾选）：不分轨，更快更稳定
- AI 增强（勾选）：重点识别和弦

输出文件
--------
- *_piano.mid / *_五线谱.pdf / *_钢琴.wav
- *_vocals/_drums/_bass/_guitar/_piano/_other.wav  分离音轨（6 轨）
