TuneScript AI V0.3 — 音乐转谱器
================================

把音频识别为钢琴 MIDI + 五线谱 PDF + 钢琴演奏 WAV。

运行要求
--------
- Windows 10 / 11
- 已安装 MuseScore Studio 4（渲染五线谱 PDF 与钢琴音色 WAV 需要）
- 首次运行需联网：下载人声/伴奏分离模型约 80MB，缓存后离线可用

使用
----
1. 双击 TuneScript AI V0.3.exe 启动
2. 选择音频文件
   - WAV / FLAC / OGG 直接识别
   - MP3 / M4A 等需同目录的 ffmpeg.exe（本包已附带）
   - NCM（网易云音乐加密文件）会自动解密后识别（支持新旧两种加密格式）
3. 选择输出目录，点「开始转谱」

两个模式
--------
- 默认：人声/伴奏分离（更准更干净；额外保存分离出的人声/鼓/贝斯/其他四轨 WAV）
- 简洁模式（勾选）：不分轨、经典流程，更快更稳定

AI 智能识别增强(和弦增强)
------------------------
勾选「AI 智能识别增强」后，分轨时用 ByteDance 钢琴转录模型重点识别
和弦(人声→和弦→贝斯 的优先级，CPU 接近实时，比 MT3 快约 6 倍)；
不分轨时用整曲 MT3(限时 90 秒)识别。
- 分轨增强需要 exe 同目录下有 piano_btd/note_F1=0.9677_pedal_F1=0.9186.pth
  模型文件（本完整包已附带，约 165MB）
- 若未找到模型或识别失败，会自动退回常规识别，不影响出谱

可选：参考谱拼接
----------------
把示例谱转成 MusicXML（oemer 等工具），命名为
    <歌名>_前奏参考.musicxml
    <歌名>_尾奏参考.musicxml
放到输出目录，转谱时前奏/尾奏会直接采用示例谱。

输出文件
--------
- *_piano.mid       钢琴 MIDI
- *_五线谱.pdf      五线谱
- *_钢琴.wav        钢琴演奏音频
- *_vocals/_drums/_bass/_other.wav  分离音轨（分离模式时）
